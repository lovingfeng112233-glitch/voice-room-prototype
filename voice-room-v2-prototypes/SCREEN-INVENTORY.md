## 规则

- 普通语音房人数：5、8、9、12、15、20。
- 20 人布局固定为 4 列 × 5 行。
- 5 人：1 个主位 + 4 个普通位。
- 8 人：4 列 × 2 行。
- 9 人：1 个主位 + 4 列 × 2 行。
- 12 人：4 列 × 3 行。
- 15 人：5 列 × 3 行。
- Public / Password 不进入一期。
- Room Chat 直接显示在房间背景上，不为每条消息添加独立底色。
- Invitation Code 与 Agency Code 是两套不同绑定关系。
- 我的首页不展示 Cash Out，不展示 Feedback。
