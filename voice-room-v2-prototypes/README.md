# Voya 语音房一期完整原型

本目录按四个模块整理，共 53 张正式页面：

- `01-auth`：注册登录、验证码、邀请码填写与绑定成功
- `02-rooms`：Party/Game 列表、搜索、创建房间、座位布局、房内、上麦、退出、礼物、游戏规则与记录
- `03-invite`：裂变首页、邀请码绑定、15%/5%/2% 三级代理、规则、记录与成员管理
- `04-me`：钱包充值、币商、Agency、Streamer Center、记录、Setting 与所有主要二级页面
